  - 核心内容：
    - **10.1 注意力提示**：
      - 理解注意力机制的核心概念：自主性提示（查询 Query）与非自主性提示（键 Key、值 Value）
      - 注意力汇聚（Attention Pooling）：通过 Query 与 Key 的匹配，引导选择最相关的 Value
    - **10.2 注意力汇聚：Nadaraya-Watson 核回归**：
      - 从非参数注意力汇聚（平均汇聚）到带参数注意力汇聚的演进
      - Nadaraya-Watson 核回归：以高斯核作为评分函数，Query 为待预测点的 x，Key 为所有训练点的 x，Value 为对应 y 值
      - 从零实现带参数的注意力汇聚模型，学习可训练的权重参数
      - 可视化注意力权重热力图，直观理解注意力在何处"关注"
    - **10.3 注意力评分函数**：
      - 注意力机制的统一数学框架：softmax(score(Q, K)) · V
      - **加性注意力（Additive Attention）**：score(q, k) = v^T tanh(W_q q + W_k k)，通过单隐藏层 MLP 计算相似度
      - **缩放点积注意力（Scaled Dot-Product Attention）**：score(Q, K) = QK^T / √d，除以 √d 防止点积过大导致 softmax 梯度消失
      - 关键区别：加性注意力用可学习参数计算相似度，缩放点积注意力直接计算向量内积
      - 使用掩蔽 softmax 处理变长序列，将填充位置的注意力权重置零
    - **10.4 Bahdanau 注意力**：
      - 将注意力机制融入 Seq2Seq 架构：编码器的隐藏状态同时作为 Key 和 Value，解码器上一时间步的隐藏状态 s_{t-1} 作为 Query
      - 注意力权重 α_t 表示解码器在时间步 t 时对编码器各时间步的"关注度"
      - 上下文变量 c_t = Σ α_t(i) · h_i，加权求和替代原 Seq2Seq 中固定的单一上下文向量
      - 对比与上一周 Seq2Seq 的区别：原方案只用编码器最后一个隐状态，Bahdanau 能动态关注不同位置
    - **10.5 多头注意力**：
      - 将 Q、K、V 通过 h 组独立的线性投影变换到不同子空间，并行计算注意力后再拼接、投影
      - 核心思想：对 Q、K、V 的特征向量进行划分，
      - 从零实现 `MultiHeadAttention` 类：包含线性投影层、缩放点积注意力、输出投影
      - 与单头对比：参数总量相近（投影后维度 = d_model / h），但表达能力更强
    - **10.6 自注意力和位置编码**：
      - 自注意力（Self-Attention）：Q、K、V 均来自同一输入序列，每个位置关注所有位置
      - 与 CNN/RNN 对比：CNN 感受野有限需多层堆叠，RNN 顺序计算无法并行；自注意力可并行计算、直接建模任意两位置依赖、计算复杂度 O(n²d)
      - **位置编码（Positional Encoding）**：自注意力本身对位置不敏感，需注入位置信息
        - 绝对位置编码：将位置 i 映射为正弦/余弦函数的固定编码，维度 j 偶数用 sin、奇数用 cos
        - 相对位置信息：PE_{pos+k} 可表示为 PE_{pos} 的线性函数，使模型能捕捉相对位置关系
      - 理解位置编码与嵌入向量相加后作为自注意力输入的原因

## 二、问题与解决

1. **问题1**：注意力汇聚理解。
   - 注意力汇聚和 CNN 中的平均汇聚等相似，区别是平均汇聚计算的值不使用权重，参与汇聚的每一个值的权重都一样，而注意力汇聚是对通过 Q 和 K 计算得到权重，再与 V 计算求得加权平均值。
   - 注意力汇聚都基于 Nadaraya-Watson 核回归，不同注意力机制的本质区别在于评分函数不同，评分函数也确定了函数权重计算的依据，例如使用常规的高斯核时，和离查询x较近的样本权重会比较高，也就是更加“注意”查询周围的样本。

2. **问题2**：代码中一些操作
    1. `unsqueeze` 进行广播：`unsqueeze` 在张量的对应维度添加一个维度，以下面代码为例：
  
    ```python
    queries, keys = self.W_q(queries), self.W_k(keys)
    # 在维度扩展后，
    # queries的形状：(batch_size，查询的个数，1，num_hidden)
    # key的形状：(batch_size，1，“键－值”对的个数，num_hiddens)
    # 使用广播方式进行求和
    features = queries.unsqueeze(2) + keys.unsqueeze(1)
    features = torch.tanh(features)
    ```

    PyTorch（以及NumPy）中` size=1 ` 的维度会自动进行广播，上面的代码相当于queries先广播与key每一个最后一维相加，接着是key的2、3维与queries的每一个2、3维相加。实际广播机制会同时将两者的形状扩展到相同的形状，然后逐元素相加。

     2. `attention_weights = masked_softmax(scores, valid_lens)` 在注意力评分函数计算中，scores 是评分函数得到的结果，进行掩码操作使valid_lens后的值的权重为0。

3. **问题3**：多头注意力注意点。
  - 对 Q、K、V 的隐藏状态进行划分后维度先变成 4D（ `(batch_size，查询或者“键－值”对的个数，num_hiddens)` 变为: `(batch_size，查询或者“键－值”对的个数，num_heads，num_hiddens/num_heads)` ），再进行变换和合并维度变为 `(batch_size*num_heads,查询或者“键－值”对的个数,num_hiddens/num_heads)` 才能直接使用定义好的 `attention` 函数。
  - 这样的操作相当于将原内容再划分当作小批量样本，`dim=0` 处的每 `num_heads` 个批次内容合并为原来的一个样本。
