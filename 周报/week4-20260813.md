  - 核心内容：
    - **Transformers 的三个基类**：
      - `PreTrainedConfig`：一个配置文件，指定模型的属性（注意力头数、词汇表大小等），是模型/权重的"说明书"
      - `PreTrainedModel`：由配置定义的模型架构，预训练模型只返回原始隐藏状态；针对具体任务需要对应的"模型头"（如 `LlamaModel` 与 `LlamaForCausalLM` 的区别）
      - `Preprocessor`（预处理器）：将原始输入（文本、图像、音频等）转换为模型数值输入，如 `AutoTokenizer` 把文本转成张量
    - **AutoClass API**：`AutoTokenizer`、`AutoModelForCausalLM` 等会根据预训练权重的名称或路径自动推断合适的架构，不用手动指定模型类
    - **加载预训练模型**：`from_pretrained()` 从 Hub 或本地加载权重与配置；`device_map="auto"` 自动把权重分配到最快的设备（GPU），`dtype="auto"` 按权重原始精度加载，避免重复加载
    - **文本生成流程**：分词器处理文本 → `return_tensors="pt"` 转 PyTorch 张量 → `.to(model.device)` 移到 GPU → `model.generate()` 生成 → `batch_decode` 将 token id 解码回文本。这个流程与我上周写的 `qwen1_5_infer.py` 完全对应
    - **Pipeline**：使用预训练模型做推理最便捷的方式，支持文本生成、图像分割、语音识别等众多任务 `pipeline("text-generation", model=..., device=...)` 
    - **Trainer**：封装完整训练/评估循环，配合 `TrainingArguments` 配置超参数（batch size、学习率、epochs 等）与 `DataCollatorWithPadding` 构造批次，减少手写训练循环的样板代码，理解微调（fine-tuning）的入口

## 二、问题与解决

1. **问题1**：pip 安装 PyTorch 时，torch 主包（约 843MB）在下载到约 730MB 处反复中断，多次重试均失败。
   - *现象*：使用南大镜像 `pip install torch torchvision --index-url https://mirrors.nju.edu.cn/pytorch/whl/cu126`，进度条每次都在 730.6/843.7 MB 位置报 `incomplete-download`，清理 pip 缓存尝试其他网上的方法后还存在 `error: could not install packages due to an oserror: [errno 28] no space left on device` 这样的错误，并且检查了 WSL 分配的空间没有问题。
   - *解决*：改用 curl 配合 `-C -`（断点续传）与 `--retry-all-errors` 直接下载 wheel 文件到本地，完整下载后用 `sha256sum` 校验哈希无误，再 `pip install` 本地文件安装成功。
   - *结论*：pip 的重试逻辑在该镜像上对大文件不够健壮，改用支持断点续传的 curl 下载大文件是更可靠的方式。

2. **问题2**：模型加载成功，但调用 `model.generate()` 生成时直接报错 `RuntimeError: Failed to find C compiler`。
   - *现象*：日志显示 Triton 在 JIT 编译 CUDA kernel 时需要 C 编译器（gcc/g++），但 WSL 环境里没有安装。
   - *解决*：`apt-get install build-essential` 安装 gcc/g++ 后重新运行，生成正常。
   - *结论*：新版 PyTorch 使用 Triton 做算子优化，运行时需要 C 编译器，环境搭建阶段应提前装好 `build-essential`。

## 3. LLM CLI demo

* 一个简单的infer

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

# 要加载的模型名称
MODEL_NAME = "models/Qwen1.5-1.8B-Chat"


def main():
    # 1. 加载 tokenizer
    # trust_remote_code=True：允许从模型仓库里加载自定义 tokenizer 配置
    tokenizer = AutoTokenizer.from_pretrained(
        MODEL_NAME,
        trust_remote_code=True
    )

    # 2. 加载预训练模型
    # torch_dtype 设置精度，节省显存并加速推理
    # device_map="auto"：自动把模型分配到可用 GPU（如多卡）
    model = AutoModelForCausalLM.from_pretrained(
        MODEL_NAME,
        torch_dtype=torch.bfloat16,
        device_map="auto"
    )

    # 3. 构造消息列表（聊天上下文）。
    # role=system 是助手人格或行为说明，role=user 是用户输入。
    messages = [
        {"role": "system", "content": "你是一个乐于助人的中文助手。"},
        {"role": "user", "content": "简单介绍一下大语言模型是如何进行推理的。"}
    ]

    # 4. 应用聊天模板，将对话格式的聊天数据转换为模型可以处理的输入格式（格式化的字符串）。
    # tokenize=False：这里不进行 tokenize 操作
    # add_generation_prompt=True：添加提示词表示需要模型生成回复 (默认False)
    prompt = tokenizer.apply_chat_template(
        messages,
        tokenize=False,
        add_generation_prompt=True
    )

    # 5. tokenizer 转 tensor，并移动到模型所在设备
    """
    text: 输入文本（字符串或字符串列表）
    return_tensors="pt": 返回 PyTorch 张量（也可以是 "tf" 表示 TensorFlow）
    padding=True 或 "max_length": 自动填充到最大长度
    truncation=True: 超过最大长度时自动截断
    max_length=512: 设置最大长度
    add_special_tokens=True: 添加 [CLS], [SEP] 等特殊 token
    return_attention_mask=True: 返回 attention mask（默认 True）
    """
    inputs = tokenizer(prompt, return_tensors="pt").to(model.device)

    # 6. 关闭梯度计算，加速并节省显存，生成格式具体看 hf 文档 
    # https://hugging-face.cn/docs/transformers/internal/generation_utils
    with torch.no_grad():
        outputs = model.generate(
            **inputs,
            max_new_tokens=256,      # 生成的最大 token 数
            do_sample=True,          # 采样生成而不是贪心解码
            top_p=0.9,               # nucleus sampling
            temperature=0.7,         # 采样温度
        )

    # 7. decode 得到原文本，去掉输入 prompt 部分
    gen_ids = outputs[0][inputs["input_ids"].shape[-1]:]
    # skip_special_tokens=True：去掉特殊符号（<s>, </s> 等）
    text = tokenizer.decode(gen_ids, skip_special_tokens=True)

    # 8. 打印最后结果文本
    print(text)


if __name__ == "__main__":
    main()
```


* 一个简单的cli

```python
import time
import threading

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, TextIteratorStreamer

MODEL_NAME = "/models/Qwen1.5-1.8B-Chat"

class QWEN1_5_Chatbot:
    def __init__(self, model_name=MODEL_NAME):
        self.model_name = model_name
        self.tokenizer = None
        self.model = None
        self.messages = [
            {"role": "system", "content": "你是一个乐于助人的中文助手。"},
        ]

    def init_model(self):

        self.tokenizer = AutoTokenizer.from_pretrained(
            self.model_name,
            local_files_only=True,        # 明确只用本地文件，不去 Hub 上找
            use_fast=True
            )

        self.model = AutoModelForCausalLM.from_pretrained(
            self.model_name,
            local_files_only=True,        # 明确只用本地文件，不去 Hub 上找
            dtype=torch.bfloat16,
            device_map="auto"           # 自动选择GPU
        )

    def generate_response(self, user_input):

        self.messages.append({"role": "user", "content": user_input})

        prompt = self.tokenizer.apply_chat_template(
            self.messages,
            tokenize=False,
            add_generation_prompt=True
        )

        inputs = self.tokenizer(prompt, return_tensors="pt").to(self.model.device)


        # TextIteratorStreamer会把模型生成的新 token 逐个翻译成文字，放进一个队列里，
        # 主程序可以一边等一边取出来打印，从而实现"边生成边显示"。
        #   - skip_prompt=True      ：跳过输出用户输入的提示词，只输出模型新生成的内容
        #   - skip_special_tokens   ：去掉 <s> </s> 这类特殊符号，只保留正常文字
        streamer = TextIteratorStreamer(
            self.tokenizer,
            skip_prompt=True,
            skip_special_tokens=True,
        )

        # 把生成模型时要用的所有参数打包成一个字典
        #（这样可以把它们整体传给上面那个线程，写起来更整齐）
        generation_kwargs = dict(
            inputs,                          # 模型的输入（已转成张量）
            max_new_tokens=256,              # 最多生成 256 个新 token
            do_sample=True,                  # 开启采样（让回答有随机性，不全选概率最高的）
            top_p=0.9,                       # 采样时只在概率前 90% 的候选里选，避免"胡说八道"
            temperature=0.7,                 # 温度：越小越保守，越大越随意
            streamer=streamer,               # 把"搬运工"接在生成器上，每生成一个 token 就通知它一次
        )

        # 线程（threading.Thread）让生成在后台跑，我们回到主程序继续打印。
        #   - target=...：线程要执行的函数（这里就是模型生成）
        #   - kwargs=...：传给那个函数的参数（就是上面打包好的字典）
        thread = threading.Thread(target=self.model.generate, kwargs=generation_kwargs)
        thread.start()   # 启动后台线程

        # 主程序这边：从 streamer 里一个个取出生成好的文字片段
        response = ""
        for chunk in streamer:                       # chunk 是一段新增文字
            for i in range(0, len(chunk), 2):        # 每 2 个字符打印一次
                print(chunk[i:i+2], end="", flush=True)   # end="" 不换行，flush=True 立即显示在屏幕上
                time.sleep(0.02)                     # 暂停 0.02 秒
            response += chunk                        # 同时把文字拼起来，方便后面存进聊天历史

        print()  # 生成结束，换行，让下一个"请输入："从新一行开始

        self.messages.append({"role": "assistant", "content": response})

        return response, self.messages

    def reset(self):
        self.messages = [
            {"role": "system", "content": "你是一个乐于助人的中文助手。"},
        ]

    def free_model(self):
        del self.model
        del self.tokenizer
        torch.cuda.empty_cache()

if __name__ == "__main__":
    # main()
    chatbot = QWEN1_5_Chatbot()
    chatbot.init_model()

    while True:
        text = input("请输入：")
        if text == "reset":
            chatbot.reset()
            print("已重置对话历史。")
            continue
        elif text == "exit":
            print("退出程序。")
            chatbot.free_model()
            break
        response, messages = chatbot.generate_response(text)
```

* 其中 `model.generate` 有几个参数可以做**调参**操作：

    - **max_new_tokens**
      中文大约 1 token ≈ 0.7–1 个汉字（跟分词器有关，只做粗略估算）。
      比如想要 800–1000 字的回答，可以设置 max_new_tokens ≈ 800 ~ 1200，再视显存和速度调整。

    - **top_p**
      把所有 token 按概率从大到小排序；
      从上往下累加概率，直到和 ≥ top_p；
      只在这个“核”里面采样，其余低概率词直接丢弃。

      - 和 top_k 的区别：
        top_k：保留前 k 个最高概率词。
        top_p：保留概率累积到 p 的那批词，数量是动态的。

    - **temperature**
      把模型算出的 logits 除以一个系数 T，再做 softmax：
      T = temperature
      T < 1：把分布压得更“尖”
      T > 1：把分布拉得更“平”

        - temperature 小（接近 0）
        把“原本就高概率”的词拉得更高
        把“原本就低概率”的词压得更低
        输出更稳定、重复性强、很少“冒险”

        - temperature 大（>1）
        高概率词和中等概率词差距被缩小
        模型更愿意尝试非主流词
        输出更多样，有创意，但也更容易胡言乱语
