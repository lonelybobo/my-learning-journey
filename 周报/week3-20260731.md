  - 核心内容：
    - **第 11 章 优化算法**：
      - **11.1 优化和深度学习**：区分"优化目标"与"深度学习目标"（优化最小化训练损失，深度学习关注泛化误差）；深度学习中的优化挑战：局部最小值、鞍点、梯度消失
      - **11.2 凸性**：凸集、凸函数定义（詹森不等式），凸函数的局部最小值即全局最小值；凸约束下的优化性质
      - **11.3 梯度下降**：一维梯度下降与学习率（过大不收敛、过小收敛慢）、多维梯度下降；牛顿法及二阶收敛性；自适应方法（预处理/特征缩放）
      - **11.4 随机梯度下降**：单样本随机梯度与全量梯度的权衡；动态学习率（多项式衰减、指数衰减）；凸目标的收敛性分析
      - **11.5 小批量随机梯度下降**：向量化与缓存的效率收益；从零实现小批量 SGD 及简洁实现；学习率与批量大小对收敛的影响
      - **11.6 动量法**：病态曲率（ill-conditioned）问题——SGD 在椭圆损失面上沿陡峭方向振荡、平坦方向收敛慢；指数加权移动平均（EMA）累积历史梯度；从零实现 + 简洁实现，对比动量对收敛速度的提升
      - **11.7 AdaGrad**：稀疏特征与学习率；核心思想——按每个坐标历史梯度平方和自适应缩放学习率，稀疏特征获得更大更新；从零实现
      - **11.8 RMSProp**：针对 AdaGrad 中梯度平方无限累积导致学习率过度衰减的问题，改用指数加权移动平均计算二阶矩；从零实现
      - **11.9 Adadelta**：无学习率的自适应算法，利用变量 Δx 的 RMS 重新缩放更新步长；与 RMSProp 对比
      - **11.10 Adam 算法**：融合动量法（一阶矩）与 RMSProp（二阶矩），加入偏差修正处理早期估计偏差；Yogi 变体对二阶矩的改进
      - **11.11 学习率调度器**：训练后期减小学习率以精细收敛；因式分解（factor）衰减、指数衰减、余弦调度、warmup 预热等策略
    - **第 12 章 计算性能**：
      - **12.1 编译器和解释器**：命令式编程（灵活、逐行执行）vs 符号式编程（先编译再执行、性能高但灵活差）；PyTorch 通过 `torch.jit.script` / `torch.jit.trace` 实现混合式编程，兼顾灵活性与性能
      - **12.2 异步计算**：PyTorch 前端调用与后端执行异步进行；通过 `torch.cuda.synchronize()` 等阻塞器控制同步；将多个操作批处理提交以提高效率
      - **12.3 自动并行**：基于 GPU 的并行计算（GPU 计算与 CPU 侧操作并行）、计算与通信并行；PyTorch 自动调度张量操作并行
      - **12.4 硬件**（理论学习）：计算机组成、内存与存储器、CPU 内核与各级缓存、GPU 大量并行核心架构、网络与总线带宽及延迟指标
      - **12.5 多GPU训练**（理论为主，无实验）：按层切分与按数据切分（数据并行）；数据并行流程：将小批量切分为 n 份分发给 n 个 GPU，各自前向/反向计算梯度，汇总所有梯度求平均后统一更新参数
      - **12.6 多GPU的简洁实现**（理论为主，无实验）：`nn.DataParallel(model)` 一行包装实现数据并行，其余内容和单 GPU 一样。
      - **12.7 参数服务器**（理论为主，无实验）：分布式训练的参数管理；环同步（Ring Synchronization）降低通信开销；多机训练；键值存储（key-value store）与异步更新
    - **第 13 章 计算机视觉（13.1-13.4）**：
      - **13.1 图像增广**：常用增广方法——翻转、随机裁剪、改变颜色（亮度/对比度/饱和度/色调）、多种增广组合（先裁剪再翻转再变色）；训练时使用增广增强泛化、预测时通常不做增广；在 CIFAR-10 上训练对比有无增广的效果

      - **13.4 锚框**：以每个像素为中心生成不同宽高比与尺度的多个锚框；交并比（IoU）衡量两框重叠程度；训练中标注锚框——为每个锚框分配真实边界框并编码类别与偏移量；非极大值抑制（NMS）去除相互重叠的冗余预测框、保留高置信度框

## 二、问题与解决

1. **问题1**：优化算法的本质：如何从原始梯度 g_t 得到更新量 Δ_t？
```

├─ 流派A：改造方向（修改"参数更新量"，替换梯度下降中的g）
│   ├─ 动量法：v_t = β*v_prev + g_t  →  Δ = lr * v_t
│   └─ Nesterov：v_t = β*v_prev + g_t(θ - β*v_prev)  → 前瞻性修正
│
├─ 流派B：改造步长（修改"学习率"，替换梯度下降的lr）
│   ├─ AdaGrad：Δ = lr / sqrt(Σg²) * g_t  （历史累积，越学越慢）
│   └─ RMSProp：Δ = lr / sqrt(E[g²]) * g_t （加入动量法思想 指数移动平均，更合理）
│
└─ 流派C：方向+步长同时改造（集大成者）
    └─ Adam：m_t = β1*m_prev + (1-β1)*g_t  （改造方向）
              v_t = β2*v_prev + (1-β2)*g_t² （改造步长）
              Δ = lr * m_hat / (sqrt(v_hat) + ε)  （两者结合）

Adadelta：x = x - sqrt(E[Δx²] + ε) / sqrt(E[g²] + ε) * g_t 自动调节学习率，不用学习率调节器
```
